# jk-map (JKまっぷ)

福井県の地元のお店や観光スポットを紹介する、シンプルでデータ駆動型のインタラクティブマップです。このプロジェクトは、単一のHTMLファイルとCSVデータソースで構築された静的ウェブサイトです。

## デモ

実際のマップはこちら: **https://github.com/code4fukui/jk-map

## 機能

- **インタラクティブマップ:** OpenStreetMapを活用し、地図上にスポットを表示します。
- **詳細情報:** マップ上のポイントをクリックすると、店舗名、電話番号、概要、定休日などの詳細を確認できます。
- **カテゴリ別表示:** 店舗は、`飲食`、`買い物`、`宿泊`などのカテゴリーごとに分類されています。
- **CSVベースのデータ:** マップのデータはすべて `jk-map.csv` ファイルから直接読み込まれるため、更新が簡単です。
- **ビルド不要:** ビルド作業は不要で、モダンなウェブブラウザ上で直接動作します。

## 動作の仕組み

マップは `index.html` でインポートされている `<csv-map>` Webコンポーネントを使用してレンダリングされます。このコンポーネントは `jk-map.csv` ファイルからデータを動的に取得し、`geo3x3` の位置情報を解析して地図上にポイントを表示します。

## 使い方とデータのカスタマイズ

プロジェクトをローカルで実行するには、`index.html` をウェブブラウザで開くだけです。

マップの内容を変更するには、`jk-map.csv` ファイルを編集します。行を追加、削除、または更新することで、表示されるポイントを変更できます。CSVファイルでは以下の列を使用します:

- `名前`: 場所・店舗の名前
- `電話番号`: 電話番号
- `カテゴリー`: カテゴリー（例: `飲食`、`買い物`）
- `icon`: カスタムマップアイコンのURL
- `概要`: 簡単な説明
- `定休日`: 定休日
- `geo3x3`: 位置情報（Geo3x3形式）
- `キャッチコピー`: キャッチコピー
